# Steam AI Research
Project to research presence and apparent impact of AI in game reviews


# Setup
````
.\setup.ps1
````

Adicionar uma biblioteca nova:

1. Instale: ``pip install nome-da-biblioteca``
2. Adicione o nome dela ao requirements.txt (na seção que fizer sentido).
3. Atualize o arquivo com as versões exatas: ``pip freeze > requirements-lock.txt``
